§ 01.b / Math & Method — 硬核审美

三个我最喜欢的离散化思想

好的数值格式不是"把导数换成差商"这么简单——它是把连续世界的对称性搬到网格上。 下面三块是我日常打交道的核心工具。 公式由 KaTeX 渲染；若 CDN 不可达，则回退为等宽 Unicode 文本。

M1

Discrete Gradient 离散梯度法

(uₙ₊₁ − uₙ)/Δt = −S·∇̄H(uₙ₊₁, uₙ)
∇̄H(v,u)·(v−u) ≡ H(v) − H(u)

算法思想 用平均向量场替代梯度，链式法则就退化成一个代数恒等式。于是 H(uₙ₊₁) = H(uₙ) 不是"近似成立"，而是每一步严格成立——跑十万步也不会能量漂移。

  • #Hamiltonian
  • #exact conservation
  • #implicit

M2

Crank–Nicolson 时间中心隐格式

(uⁿ⁺¹ − uⁿ)/Δt = ℒ((uⁿ⁺¹ + uⁿ)/2)
⇒ ‖uⁿ⁺¹‖₂ ≤ ‖uⁿ‖₂

算法思想 把时间导数放在半步中点上，对称性换来二阶精度 + A-稳定： 步长不再被 Δt ≲ Δx² 掐住脖子。 代价是每步解一个线性系统——这通常是划算的交易。

  • #A-stable
  • #2nd order
  • #diffusion

M3

Scalar Auxiliary Variable 标量辅助变量 (SAV)

∂ₜφ = −ℒμ, μ = δE/δφ
r = √(E₁(φ)+C₀), d/dt (E₂(φ)+r²) ≤ 0

算法思想 梯度流的非线性项是稳定性分析的噩梦。SAV 把非线性能量藏进一个标量 ODE， 格式立刻变成线性、二阶，且修正能量严格耗散。相场、液晶、两相流都靠它。

  • #gradient flow
  • #linear scheme
  • #phase field

§ 01.c / Live experiment — 在浏览器里积分一个 PDE

CFL 稳定性实验台

一维线性对流方程 ∂ₜu + a·∂ₓu = 0， 周期边界，高斯波包初值。拖动 Δt 改变 ν = aΔt/Δx， 看 CFL 条件 |ν| ≤ 1 被打破的瞬间。 纯 Canvas 手写，无第三方库。

stable scheme upwind CFL ν = 0.60 ‖u‖∞ = 1.000 steps = 0
你的浏览器不支持 canvas，无法显示数值解图像。

按 Run 开始积分 · 默认 ν=0.60 稳定，把 Δt 推过 0.0040 就会跨过 CFL 极限

为什么值得玩 Upwind 在 0 ≤ ν ≤ 1 时单调稳定，但耗散——波包会越跑越矮； Lax–Wendroff 二阶、几乎不耗散，却在 ν > 1 时指数爆炸； FTCS 无论如何都不稳定。这就是数值格式的性格：精度、稳定性、单调性不可兼得。

⌘ snippet · 八行辛积分器

# leapfrog (kick–drift–kick)：辛的，能量不漂
def leapfrog(q, p, dt, n, grad_V):
    for _ in range(n):
        p -= 0.5 * dt * grad_V(q)   # 半步踢
        q += dt * p                  # 整步漂
        p -= 0.5 * dt * grad_V(q)   # 半步踢
    return q, p
